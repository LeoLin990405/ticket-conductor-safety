# WP0 spikes

`capability-spike/` is a separate Forge app used to answer the week-1 questions. It is not the Ticket Conductor app. Do not deploy it from the repo root, and do not copy its `app.id` onto the product manifest.

The decisions, the doc URLs, and the commands for the dev site are in [docs/SPIKES.md](../docs/SPIKES.md).
